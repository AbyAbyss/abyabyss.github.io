One wire, four engines

The AG-UI wire is the standard all four engines speak. The Python server has the TypeScript server's routes, status codes, JSON bodies and event frames, so any client works against any server:

The Python server

agentkit.server is one framework-free ASGI app. serve runs it on uvicorn (extra server):

Inside another ASGI app, create_agent_handler(agent, base_path="/api/agent", app=other_app) answers its routes and hands any other path to app. The routes are the TypeScript list: POST /session, GET /events (SSE, with Last-Event-ID replay), GET /events/all, POST /send, /approve, /reject, /answer, /cancel, GET /approvals, /history, /artifacts, GET|POST /mode, /workflows*, /mcp* (with the OAuth callback), /rag/*, /models*, /health, /capabilities. With transport="websocket", /events is a WebSocket through the ASGI websocket scope. Auth, tenant isolation, CORS, Host checks, the 4 MiB body limit and the session cap are ported from handler.ts.

The Python client

agentkit.client talks to any AgentKit server:

It reconnects dropped streams, connect_with_retry waits for a server that is still starting, and connect_agents(url) talks to serve_agents. The session hub folds events with the same reducers as the TypeScript client (conversation, pending, todos, usage, workflow). The event stream starts with the first subscriber; wait for session.status == "open" (or hub.status) before a send whose events you must not miss.

How the sameness is checked

The client contract, in all sixteen pairings. A contract host in each language (sdks/conformance/contract/ts_host.mjs, python_host.py, the Go one in sdks/go/internal/contracthost and the Rust examples/contract_host.rs) builds an agent from a JSON config and serves it on a free port (POST /serve, /serve-agents, /close). TypeScript's own packages/server/src/client-contract.test.ts runs unmodified against a host (a vitest setup redirects createAgent and serve to it), and its Python port sdks/python/tests/server/test_client_contract.py does the same, as do the Go and Rust ports:

The wire frames, byte for byte. sdks/conformance/fixtures/wire.json holds the AG-UI frames the TypeScript adapter produces for every event name; the Python server replays them exactly. CI regenerates every fixture from the TypeScript source and fails on any difference.
