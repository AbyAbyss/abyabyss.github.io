    Class SettingsService

    Layered settings with provenance.

    Flat dotted keys rather than a nested tree: merging nested objects across layers means deciding, per key, whether a layer replaces or extends what is under it — and every codebase that has tried has ended up with both and no way to tell which you are getting. a.b.c is unambiguous.
