WALLElives in the corner of your screen.

A desktop AI companion. Press Ctrl+Shift+Space, ask it to open an app or check your git status, and it answers in a speech bubble with a face to match.

It is a finished little experiment, not a product. The code works and the ideas are all here, so poke around, build it, borrow what you like.

Meet the mascots

Two characters, one corner.

WALLE is a small robot on tracks with glowing eyes and an antenna. DuDu is a green parrot on a perch. You switch between them in Settings without restarting. Try it on the little one living in the bottom-right of this page.

Seven emotions. Click a face.

The artwork is from the app. Your pick shows up on the mascot in the corner.

WALLE is idle. It drifts a few pixels now and then, so it never looks frozen.

Animations

Wave, dance, thumbs up, confused, excited run, stretch, and a reaction when you click to pet it. Try clicking the one in the corner.

Sounds

Each animation has its own little sound, synthesized live with the Web Audio API. No audio files. DuDu chirps in syllables when it talks. You can turn sounds off.

Speech bubbles

Replies and greetings pop up above the mascot, with lines for the time of day, finished and failed tasks, and idle moments. Drag it anywhere and it remembers.

What it can do

Small friend, real hands.

Hover a card and watch the corner. Everything here is in the code today.

  • AI providers:
  • Anthropic
  • OpenAI
  • OpenRouter
  • Ollama (local)

Talk to it

  • A floating chat panel, opened with Ctrl+Shift+Space
  • Push-to-talk voice input
  • Conversation history saved in SQLite
  • Optionally adds the active window title and a clipboard preview to the prompt

It does things

  • Runs shell commands, launches apps, shows notifications
  • Runs saved multi-step workflows
  • Cron schedules that fire actions in the background
  • Developer mode: finds the git repo from the window title and reads status, log and diff

It asks first

  • Each action is rated safe, moderate or dangerous before it runs
  • Manual review mode asks you first
  • A trust score per action learns from what you approve
  • API keys live in the OS credential store, never in the config file

It remembers

  • Remembers lasting preferences about you, stored locally
  • Spots actions you repeat and suggests automating them
  • Background nudges with limits built in so they don't nag
  • An insights dashboard of usage, trust scores and saved memories

Show your work

  • A panel narrates each step as it happens (Ctrl+Shift+W)
  • The AI picks an emotion for every reply
  • A dance or thumbs up when a task works, a confused shrug when it doesn't

Plugins and an early recorder

  • Built-in plugins you can switch on and off
  • External plugin manifests in ~/.walle/plugins
  • A marketplace search
  • A recorder that captures a session's steps into a list (early)

How it works

A webview on top, Rust underneath.

The mascot is a transparent always-on-top window drawn in SVG and CSS. The brain is a Rust backend.

  1. You ask. Ctrl+Shift+Space opens the chat window and you type, or push to talk.
  2. The agent calls a model. Anthropic, OpenAI, OpenRouter or a local Ollama, with optional routing between a default and a complex model.
  3. Actions get a risk rating. Safe, moderate or dangerous. Manual review mode asks you before anything runs.
  4. The action runs. A shell command, an app launch, a git read, a notification or a workflow step.
  5. The mascot answers. A speech bubble, one of seven faces, a bounce and a sound.

Under the hood

Shell
Tauri v2, with a window per job: mascot, chat, setup, settings, insights
Frontend
React 19 and TypeScript, built with Vite
Backend
Rust: agent/ (LLM calls, routing, trust, learning, watchers) and commands/ (shell, apps, git, schedules, plugins)
Memory
SQLite through sqlx, in the app data folder
Secrets
OS credential store through the keyring crate
Sound
Web Audio API, no audio files

Windows runs shell commands in PowerShell. macOS uses zsh -c, AppleScript for the active window, and open -a for apps. On Linux, chat, shell commands and workflows work, but launching apps isn't wired up.

Build it

First launch

macOS will say it can't verify walle (free side project, not notarized).

An app you build on your own machine opens normally. This applies to a build you copy to another computer, because it is not code-signed.

macOS

Open System Settings → Privacy & Security and click Open Anyway, or run this in Terminal:

xattr -dr com.apple.quarantine "/Applications/walle.app"

Windows

SmartScreen shows a prompt. Choose More info → Run anyway.

Linux partly supported

Chat, shell commands and workflows work, but launching apps isn't wired up. There is no packaged build, so build it yourself.

Build from source

A few commands, then say hi.

First run opens a setup window that asks for your AI provider's API key. To change it later, open the chat and click the gear.

  • Windows 10/11 or macOS 11+
  • Rust stable
  • Node.js 20+

1Get the code

git clone https://github.com/AbyAbyss/my_walle.git
cd my_walle
npm install

2Run it in development

Vite and Tauri together.

npm run tauri dev

3Build a desktop bundle

An .msi on Windows, a .dmg on macOS.

npm run tauri build

4Or target a Mac chip

Add the targets first with rustup target add aarch64-apple-darwin x86_64-apple-darwin.

npm run tauri build -- --target aarch64-apple-darwin   # Apple Silicon
npm run tauri build -- --target x86_64-apple-darwin    # Intel

5If the build complains about a CI flag

If tauri build fails with a --ci flag error, unset CI (in Git Bash):

CI= npm run tauri build
