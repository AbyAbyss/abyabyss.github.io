Streaming & wire protocol

Connect a frontend to @agentkit/server over AG-UI SSE

UI apps never import @agentkit/core in the browser. Run the agent with @agentkit/server (serve() or Express wrapper), then connect from the client with @agentkit/client, framework hooks, or raw fetch + EventSource (or WebSocket).

Architecture

Default agent URL in examples: http://127.0.0.1:8787 (express-api, nextjs-chat, vanilla-js-ui). Workflow UI uses :8788.

HTTP endpoints

MethodPathPurpose
GET/healthLiveness
GET/capabilitiesAgent capability flags + enriched models block
GET/modelsList registry entries + userConfigurable flag
POST/models/default{ modelId } — hot-swap default model
POST/models/addAdd BYOK model (when userConfigurable)
POST/models/test{ modelId } — connectivity ping
POST/models/refreshRe-sync Ollama tags into registry
POST/sessionCreate or resume a wire session → { sessionId }
GET/events?sessionId=…SSE stream of AG-UI events
POST/send{ sessionId, input } → run turn
POST/approveApprove a pending tool call
POST/rejectReject approval
POST/answerAnswer elicitation { sessionId, requestId, choice }
POST/cancelCancel in-flight work
POST/saveWorkflowPersist generated workflow

Optional headers: Authorization: Bearer <token>, x-agentkit-tenant: <tenant> (multi-tenant sessions).

CORS is enabled for browser clients (Access-Control-Allow-Origin: * on the default server).

Event stream (SSE, default)

  1. POST /session with {} (or { "sessionId": "existing" }).
  2. Open EventSource on GET /events?sessionId=<id>.
  3. Each message is JSON: { type, payload, timestamp }.
  4. POST /send with { sessionId, input: "your message" }.

Event stream (WebSocket, optional)

Pass transport: "websocket" to serve(). Connect a WebSocket client to ws://host:port/events?sessionId=<id>. Messages use the same { type, payload, timestamp } JSON shape as SSE. REST routes (/send, /approve, …) are unchanged.

@agentkit/client uses SSE by default; use raw ws or extend your client for WebSocket transport.

Errors & reconnect

  • session.send throws when the server returns { error } (500) — show the message; do not assume partial stream means success.
  • SSE disconnect: EventSource auto-reconnects in browsers; re-bind handlers or use @agentkit/client which opens one stream per connect().
  • 404 on /events: session expired server-side; POST /session again.
  • Auth: pass token in connect() options; implement auth on serve() to validate Authorization.

Local dev checklist

Set NEXT_PUBLIC_AGENT_URL or VITE_AGENT_URL when the agent is not on 127.0.0.1:8787.

Custom Node servers can reuse model routes with handleModelRoutes from @agentkit/server — see Models & switching.
