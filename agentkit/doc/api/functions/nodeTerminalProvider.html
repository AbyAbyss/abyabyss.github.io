    Function nodeTerminalProvider

    • nodeTerminalProvider(config?: NodeTerminalsConfig): TerminalProvider

      A persistent shell over pipes.

      This is deliberately not a PTY. A real terminal needs node-pty, which is a native module, and making the whole runtime depend on a compiler to get a bash tool is a bad trade. Pipes keep state — cwd, exported variables, an activated virtualenv, a running REPL — which is the reason to want a persistent session at all.

      What pipes do not give you is a TTY: no job control, no line editing, no curses UI, and programs that check isatty() will take their non-interactive branch. Mount a node-pty-backed provider instead when a session needs those; the tools do not change, which is the point of the seam.
