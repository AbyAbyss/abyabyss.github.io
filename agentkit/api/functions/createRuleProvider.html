    • createRuleProvider(rules: Rule[], opts?: RuleProviderOptions): Provider

      An offline model that answers by reading the conversation: the first rule whose match fits the latest user message (or predicate) replies with text, thinking, tool calls, or a function of the context returning any of those. A tool-call reply whose tools already returned this turn is skipped, so listing "call the tool" before "answer from its result" sequences a turn (repeat: true opts a rule out of that).

      registerProvider("demo", () => createRuleProvider([
        { match: /weather in (\w+)/i, reply: (c) => ({ toolCalls: [{ name: "get_weather", args: { city: c.match?.[1] } }] }) },
        { match: /weather/i, reply: (c) => `It is ${c.toolResults[0]?.content}.` },
      ], { fallback: "Ask me about the weather." }));
      createAgent({ provider: { default: "demo/scripted" } });
