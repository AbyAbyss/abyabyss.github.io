    Interface EventMap

    Event name to listener signature. Augment it from anywhere:

    declare module "@agentkit/kernel" {
      interface EventMap {
        "tools/pre-execute": (
          exec: ToolExecution,
          next: () => Promise<ToolDecision>,
        ) => Promise<ToolDecision>;
      }
    }

    A listener whose last parameter is named next is a waterfall listener: it may transform the arguments, short-circuit with its own return value, or delegate to the rest of the chain.
