    Class Fiber

    A plugin's lifecycle handle and the owner of everything it registered.

    A fiber holds two teardown stacks. Runtime effects — tools, listeners, services, child plugins — unwind whenever the plugin stops, which happens both on disposal and when a dependency disappears. Own effects unwind only on disposal, because they are what lets a stopped fiber rejoin the tree when its dependency comes back.
