How it works

Your agent on a server. Your UI on a hook.

Everything on the left is what an agent product needs before it does anything useful. In AgentKit each one is a line of config or a hook you call.

What you'd write by hand

Per project, per team, again.

  • Streaming server and reconnects server.ts
  • Sessions and message history sessions.ts
  • An approval queue and its UI approvals.tsx
  • Tool schemas and validation tools.ts
  • MCP clients and OAuth mcp.ts
  • Tracing, tokens and cost maths tracing.ts
  • Retries, budgets and timeouts guard.ts

All of it ships in the SDK.

server.ts@agentkit/core + server
import { createAgent } from "@agentkit/core";
import { serve } from "@agentkit/server";

const agent = createAgent({
  provider: "anthropic",
  tools: [getOrder, refundOrder],
  approvals: { policies: { refund_order: "approve" } },
  telemetry: { service: "support-bot" },
});

await serve(agent, { port: 8787 });

Batteries included, all optional

Everything an agent needs. Mount what you use.

Each battery is a plugin on the same kernel, so you can swap any of them for your own without forking anything.

Guardrails

The console

Get started

Running in a minute. No API key needed.

The tour walks through every feature on a mock model, so you can see it all before you spend a cent.

# clone and build
git clone https://github.com/AbyAbyss/agentkit.git
cd agentkit && pnpm install && pnpm build

# every feature, 21 stops, no API key
pnpm example:tour

# the same tour as a live dashboard
pnpm example:tour:web
import { createAgent } from "@agentkit/core";
import { z } from "zod";

const agent = createAgent({ provider: "anthropic" });

const result = await agent.run("Summarise this changelog", {
  output: z.object({ summary: z.string(), risk: z.enum(["low", "high"]) }),
});
result.output; // typed and validated
