01 Why AgentKit

An agent engine, not a framework.

Most agent tools make you adopt their UI and hosting. AgentKit is a config-first headless SDK you import — same verbs in-process, over @agentkit/client, and in React hooks.

1
Configure

Call createAgent({ … }) or a preset (createUIPreset, createCLIPreset, createBackendPreset) — registry, tools, memory, MCP. One config object, fully typed.

2
Run or stream

Use agent.run() for a one-shot typed result, or agent.session() for a live, interactive conversation.

3
Render

Typed events stream out — tokens, plans, approvals, cost. Your UI just listens and draws. No lock-in.

🎛️

Bring your own UI

React, Vue, Svelte, a terminal, or no UI at all. The engine never touches your front end.

🔌

Cloud + local models

Anthropic, OpenAI, built-in Ollama, and createOpenAICompatibleProvider. Registry + listOllamaModels().

🔄

Model hot-swap

ModelRegistry.resolveActive() on every send(). Switch with agent.models.setDefault() — session memory preserved.

🔗

Wire parity

session.models.list/setDefault/test/add/refresh on client and server (GET/POST /models/* via handleModelRoutes).

🧩

Tools & MCP

Zod-typed tools plus Model Context Protocol servers over stdio or HTTP.

🛡️

Human-in-the-loop

Plan mode, approval gates, and elicitation arrive as events you can pause on and resolve.

🧠

Smart context

Adaptive TOON encoding and automatic compaction keep prompts small and cut token cost.

⚛️

React model picker

useModels(baseUrl) + ModelPicker — zero custom fetch for model switching in UI apps.

🧪

Test without keys

Mock provider, record/replay harness, and examples/ollama-local — CI-test with zero API calls.
