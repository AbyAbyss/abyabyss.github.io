Download

Get Helpy.

Free for macOS, Windows and Linux. Installers are on the Releases page.

macOS

Macs with Apple Silicon (M1 or later). Open the .dmg and drag Helpy into Applications.

Download .dmg

First launch: the build isn't signed, so macOS says it can't verify Helpy. Open it once, then click Open Anyway in System Settings → Privacy & Security. If macOS says the app is damaged, run this in Terminal:

xattr -dr com.apple.quarantine /Applications/Helpy.app

Windows

Windows 10 or 11, 64-bit. Run the installer.

Download .exe

First launch: the build isn't signed, so SmartScreen may warn you. Click More info → Run anyway.

Linux

64-bit, X11 (Wayland is best effort). Make the AppImage executable and run it.

Download .AppImage

Prefer a package? The .deb and .rpm are on the release page.

Intel Mac, or no build for your computer? Build it from source. Older versions are under all releases.
