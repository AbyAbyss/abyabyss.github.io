    Everything you copy,

    Search

    Searchable history

    Press ⌘⇧V, start typing, and the list filters instantly. It matches text, file names and the app a copy came from.

    Paste

    Paste straight back

    Pick an item and Yankit pastes it into the app you were just in.

    Pin

    Pin what matters

    Pinned items are exempt from the rolling limit and never auto-deleted.

    Prune

    Prune on the fly

    Delete any single item with the row's × button or ⌘⌫.

    Tune

    Yours to tune

    A configurable cap (default 30) trims the oldest items, with optional auto-expiry by age.

    PRIVATEPrivacy

    Privacy-first

    Skips password-manager content, dims while paused, and keeps its data out of Spotlight and Time Machine. Nothing leaves your Mac: no account, no sync, no telemetry.

    Pause

    Pause when you need to

    One click silences capture for an hour, until tomorrow, or until you resume.

    03 How it works

    Two paths,
    one shared clipboard.

    Yankit lives in the menu bar: no Dock icon, no window in your way. A lightweight monitor watches the system pasteboard and records each new copy. When you pick an item, it goes back on the pasteboard and Yankit pastes it where you were.

    Capture. The monitor skips password-manager content, respects pause and excluded apps, and ignores Yankit's own pastes.

    Store. One SQLite table for metadata and text. Image and file payloads stay out of the database so it stays small and fast.

    Recall. Only the row you pick is loaded in full. Without Accessibility access, Yankit still puts your pick on the clipboard for a manual ⌘V.

    keys only

    no mouse needed

    ! First launch

    macOS will say it can't verify Yankit (free side project, not notarized).

    1. Open System Settings → Privacy & Security and click Open Anyway.
    2. Or run this in Terminal:
      xattr -dr com.apple.quarantine /Applications/Yankit.app
    3. For one-touch paste, grant Yankit Accessibility access when prompted (System Settings → Privacy & Security → Accessibility).

    Without Accessibility, Yankit still places your pick on the clipboard so you can paste it yourself with ⌘V.

    06 Build from source

    Three commands,
    then ⌘R.

    The Xcode project is generated from project.yml with XcodeGen, so it is not committed to the repo.

    Requirements

    • macOS 14 (Sonoma) or later
    • Xcode 15 or later
    • XcodeGen (brew install xcodegen)

    Press ⌘R to run and ⌘U to run the tests. A clipboard icon appears in the menu bar. Grant Accessibility access when prompted for one-touch paste.

    Terminal

    # 1. install XcodeGen

    brew install xcodegen

    # 2. clone the repo

    git clone https://github.com/AbyAbyss/Yankit.git

    # 3. generate the project and open it

    cd Yankit && xcodegen generate && open Yankit.xcodeproj
