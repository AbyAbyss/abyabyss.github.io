Tests (pm.test)

✓Status is 200
✓Response time < 500ms
pm.test("Status is 200", function() { pm.expect(pm.response.status).to.equal(200); });

Demo only. Status codes and bodies are scripted, the time is random, and the size is the byte count of the text shown. In the real app, the numbers come from a request you actually send. Shortcut there: Ctrl + Enter.

What's in the box

Everything an API poke needs

Eight things the app does today, nothing from a someday list.

Send real HTTP requests

GET, POST, PUT, PATCH and DELETE with params, headers and body. The response shows status, timing, size and formatted JSON.

GET POST PUT PATCH DELETE

Environment variables

Define a base URL, tokens and more per environment. Use them in URLs and headers, with live highlighting.

{{base_url}}/users

Collections and history

Organize requests in folders, search the sidebar, and reopen recent calls.

Postman-style scripts

Pre-request and test tabs with pm.test, pm.expect, pm.environment and pm.response.

Response timeline

DNS lookup, TCP connect, TLS handshake, TTFB and download, broken down in one view.

Built-in performance tests

Virtual users, ramp-up profiles, think time, and per-endpoint stats with charts and saved-run comparison. Spawned as concurrent async workers in Rust, looping through the requests you pick from a collection.

Stays on your disk

Collections, environments, request details and perf runs live in SQLite, locally.

Also Dark mode that keeps the cartoon charm. Send: Ctrl + Enter Save: Ctrl + S On macOS, use ⌘ instead of Ctrl.

How it works

Three panels, one request

REST Client is a Tauri 2 desktop app. React draws the window, Rust does the real work.

You press Send

The React frontend calls a Tauri command with your method, URL, headers and body.

React 19 + Tauri 2

Rust makes the call

The backend executes the request, measures timing, and returns status, headers, body and timeline data.

Rust + reqwest

It lands on disk

Collections, environments, request details and perf runs are stored in a local database. Perf tests run as concurrent async workers.

SQLite

Get it running

Build it yourself

There are no prebuilt installers yet and no releases on GitHub, so for now you build it from source. It takes a few minutes once the tools are in place.

Requirements

  • Node.js 18+
  • Rust (stable)
  • Tauri prerequisites for your OS

Not sure about the last one? The Tauri prerequisites guide lists what each OS needs.

Run in dev mode 
git clone https://github.com/AbyAbyss/RestClient.git
cd RestClient
npm install
npm run tauri dev

Then press Send in the app window.

Make a release build

Packages the app for your current OS. Artifacts land under src-tauri/target/release/bundle/.

Build 
npm run tauri build

If you build on your own machine, the result opens normally. The notes below matter once you copy a build to another computer.

Source on GitHub

First launch

macOS will say it can't verify REST Client (free side project, not notarized).

There are no prebuilt installers yet, so this applies to builds you copy to another machine. An app you build locally opens normally. The build is not code-signed, so the OS asks you to confirm the first time.

macOS

Open System Settings → Privacy & Security and click Open Anyway, or run in Terminal:

$ xattr -dr com.apple.quarantine "/Applications/REST Client.app"

Windows

SmartScreen shows a prompt. Choose More info → Run anyway.

Linux: the README has no first-launch steps for it, so none are listed here.
