Find where your disk space went.

wimys_crumb is a friendly disk-space scanner for macOS. It walks every volume, totals the same folder names wherever they hide, and lets you reclaim the dead weight safely. Trash by default, Undo within reach.

Feature complete, v0.1.5

    How it works

    Fast, bounded, off the main thread.

    The scan tree lives in a SQLite file on disk, never in memory, so a bigger drive does not mean a bigger app.

    StackSwift 5, SwiftUI, GRDB. macOS 14 (Sonoma) or later. Xcode 15 or later to build.
    Where data lives~/Library/Application Support/wimys_crumb/

    wimys_crumb walks the filesystem off the main thread and streams every directory, plus the top-N largest files, into a per-scan SQLite database through GRDB. The interface reads from that database with short-lived queries.

    That is the whole trick. Because the scan tree never lives in RAM, memory stays bounded however large the disk is. Quit and relaunch, and you land back on your last scan instantly.

    Memory stays bounded regardless of disk size.Project README

    01

    Walk the drive

    Every volume is scanned with FileManager off the main thread. About 5 million files take a few minutes. Pause and cancel are on the Scanning screen, with the biggest folders showing as they are found.

    02

    Stream to SQLite

    Directories and the heaviest files stream into a per-scan database on disk. Old scans stay as snapshots you can browse or delete in Settings.

    03

    Read, never hold

    Every screen asks the database a small question and lets go of the answer. That is why a 5M-file scan browses in well under 200 MB.2

    04

    Delete in one place

    Every destructive action goes through a single DeleteService. It checks the protected-path list, moves items to the Trash, then patches the SQLite tree so the next query reflects reality without a rescan.

    Groups

    The same names, added up.

    One folder is a rounding error. Forty-seven of them with the same name is a problem. Groups totals every instance across the disk.

    Every node_modules, DerivedData, Caches, __pycache__, Pods, target and .venv is totalled across the drive. One click expands every instance.

    Safety

    Delete with a net.

    A cleaning tool is only as good as its worst mistake, so the dangerous paths are off the table before you start.

    Trash by default, with Undo.How every delete works

    System folders are protected in code. Anything you delete goes to the Trash unless you explicitly choose to delete it forever, and Undo is one click away. You can add your own protected paths in Settings, and the app only sees what macOS lets it, so Full Disk Access is a choice you make.

    2. Protected list check
    3. Trash
    4. Undo

    Known gap: a real Undo beyond the macOS Trash window is on the roadmap as snapshot quarantine.

    Also in this edition

    Small print, honestly.

    The rest of the paper, in short items.

    Private by design

    Runs entirely on your Mac. No telemetry, no sync, no account. Scan data lives under ~/Library/Application Support/wimys_crumb/.

    Scheduled scans

    Switch on a schedule in Settings, pick how often, and optionally scan only on power. They run when the app is opened, not in the background.1

    JSON export

    Settings can export your scan as JSON, if you want the numbers somewhere else.

    Full Disk Access

    Grant it to see everything. Without it the app still works, skips the locked-down areas, and shows a banner saying how many folders it could not read.

    Any folder, not just drives

    The Start screen lists mounted volumes and recent scans. Prefer a single folder? Use "Pick a specific folder".

    Snapshots

    Past scan databases can be browsed and deleted from Settings, or cleared all at once. Detection shows the read-only group catalog and the large-file threshold.

    How to installFree

    1. Download and drag

      Open the DMG and drag wimys_crumb into Applications.

    2. macOS can't verify it

      wimys_crumb is a free side project and is not notarized. Open System Settings → Privacy & Security and click Open Anyway, or run in Terminal:

      xattr -dr com.apple.quarantine /Applications/wimys_crumb.app

    3. Let it see everything

      Grant Full Disk Access (System Settings → Privacy & Security → Full Disk Access) so the scan can read protected folders. It works without, and tells you how many folders it skipped.

    Do it yourself  /  Build from source

    Prefer to build it?

    The Xcode project is generated from project.yml, so it is not committed. Press ⌘R to run. It opens on the Start screen and lists your mounted volumes. Click Scan Macintosh HD to begin.

    • macOS 14 (Sonoma) or later
    • Xcode 15 or later
    • XcodeGen, via brew install xcodegen

    Repository on GitHub and XcodeGen.

    1. Install XcodeGen
    brew install xcodegen
    2. Clone
    git clone https://github.com/AbyAbyss/wimys_crumb.git
    3. Generate and open
    cd wimys_crumb && xcodegen generate && open wimys_crumb.xcodeproj
    After adding, removing or renaming files
    xcodegen generate
