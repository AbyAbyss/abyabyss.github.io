Getting started (Go)

Install the Go module and run your first agent in Go

Getting started with Go

sdks/go is a full port of the AgentKit engine, not a client wrapper: providers, tools, memory, MCP, RAG, workflows, approvals, the plugin kernel, the workspace, the server and the client all run in your Go process. TypeScript stays the reference; shared fixtures and a client contract suite check that all four engines (TypeScript, Python, Go and Rust) behave the same.

The module is github.com/AbyAbyss/agentkit/sdks/go and its root package is agentkit. Releases are tagged sdks/go/vX.Y.Z, the Go convention for a module in a subdirectory.

Install

Go 1.25 or newer.

There are no extras to choose: the base module runs the mock provider, in-memory stores and SQLite (pure Go, no cgo). Heavier backends are opt-in imports, so a program that never imports them does not link their drivers:

ImportBringsFor
github.com/AbyAbyss/agentkit/sdks/go/memory/postgrespgxPostgres memory
github.com/AbyAbyss/agentkit/sdks/go/memory/redisgo-redisRedis memory
github.com/AbyAbyss/agentkit/sdks/go/connectors/postgrespgxthe SQL connector's postgres dialect (PgBouncer-safe)
github.com/AbyAbyss/agentkit/sdks/go/connectors/mysqlgo-sql-driver/mysqlthe SQL connector's mysql dialect
github.com/AbyAbyss/agentkit/sdks/go/connectors/mongomongo-driver v2the Mongo connector

Import them for their side effect (import _ "github.com/AbyAbyss/agentkit/sdks/go/memory/postgres"); each registers its backend from init(). Providers are raw HTTP, so no vendor SDK is needed.

Your first agent

Every call that does I/O takes a context.Context, and failures come back as an error where TypeScript throws.

Set ANTHROPIC_API_KEY (or another provider's key). The config is a typed struct whose fields follow the TypeScript keys; see Config in Go.

The four shapes

The README's four createAgent shapes, in Go. Each runs on the mock provider in sdks/go/readme_shapes_test.go. The snippets below assume ctx and an agent a from the program above.

A: backend task in, typed result out.

B: full UI agent. The agent runs behind the AG-UI server; any frontend connects, including the TypeScript @agentkit/client and the React hooks.

C: backend with progress and approvals.

D: terminal coding agent.
