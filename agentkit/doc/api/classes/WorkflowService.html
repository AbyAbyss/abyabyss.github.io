    Class WorkflowService

    Deterministic multi-step work, as a seam.

    The distinction from the agent loop is who decides the order. A loop lets the model choose the next action; a workflow fixes it in advance. Both are useful, and the mistake is making one pretend to be the other — a model asked to follow nine steps exactly will eventually improvise, and a fixed pipeline cannot react to what it finds.

    Steps declare needs, so independent ones run concurrently without the author scheduling anything.
