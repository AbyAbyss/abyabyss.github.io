How it works

Fast, bounded, off the main thread.

wimys_crumb streams every directory into a per-scan SQLite database, so memory stays flat no matter how big the disk.

01

Walk the drive

Every volume is scanned with FileManager off the main thread — about 5 million files in a few minutes.

02

Stream to SQLite

Directories and the largest files stream into GRDB on disk. The UI reads with short-lived queries, never holding the tree in RAM.

03

Delete safely

Every destructive action funnels through one DeleteService that checks protected paths and moves items to Trash with Undo.
