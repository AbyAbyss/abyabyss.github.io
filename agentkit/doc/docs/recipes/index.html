Ollama local (ollama-local)

Discovers tags via listOllamaModels(), builds a createUIPreset registry, and serves on :8796 with standard /models routes. Falls back to mock when Ollama is offline.

Probe: GET http://127.0.0.1:8796/models, POST /models/default, POST /models/refresh.

Composer UI (composer-ui)

Vite UI with a custom Node server that delegates model management to handleModelRoutes from @agentkit/server (same routes as serve()).
