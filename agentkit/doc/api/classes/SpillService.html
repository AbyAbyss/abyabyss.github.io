    Class SpillService

    Somewhere to put output that is too big for the context window.

    grep matching four thousand lines is not a bug — the answer really is four thousand lines. Truncating throws away what the model needed; inlining it costs the window. Spilling keeps the whole result addressable and returns a head plus a locator, so the model reads more only when it must.
