Caveats

  • dist/ is not committed — git installs clone source only. Either publish built tarballs to npm, or prefer link / file: below and run pnpm build in the AgentKit repo.
  • workspace:* dependencies — installing one folder from git does not resolve sibling packages automatically. Install each required path (see tables above), or use link / file:.
  • Rebuild after changes — git installs do not watch the monorepo; bump the ref or reinstall to pick up updates.

For day-to-day SDK development, link or file: is usually easier than git URLs.
