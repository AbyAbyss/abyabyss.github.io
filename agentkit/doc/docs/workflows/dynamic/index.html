Dynamic workflows (experimental)

NL-generated DAGs, graph plugins, and save-to-static

Experimental / unstable: APIs live under experimental.dynamicWorkflows and may change between minors. Graph generation is heuristic (fixed 3-node template today), not a full planner model.

Dynamic workflows turn each session.send() into: generate a DAG → run nodes in dependency order → optionally prompt to save the graph as a static workflow definition.

When to use

Use dynamicUse static workflows instead
User describes a task in chat; you want a visual DAGPipeline is fixed at deploy time
Prototype repeat detection → save as templateProduction cron / API without NL
React Flow or custom graph UI via pluginsHeadless agent.workflows.run(id) only

Requirements

Both must be set:

  1. workflows: {} — memory store (for saveWorkflow)
  2. experimental.dynamicWorkflows.enabled: true

When dynamic mode is on, session.send does not run the normal reasoning loop — it only runs the dynamic pipeline and returns the last node’s output.

In-process demo: examples/workflow-demo/src/dynamic.ts (pnpm example:workflow:dynamic).

Config (DynamicWorkflowsConfig)

FieldDefaultBehavior
enabledfalseSwitches session send to dynamic runner
autoPromptSavetrueEmit workflow:save:prompt when repeat threshold met
repeatAfter2Min similar runs (including current) to prompt save
similarityThreshold0.82Cosine similarity on simple word-frequency embeddings

Similarity is local (embedTask / checkRepeat in @agentkit/core) — no embedding API.

Lifecycle and events

WorkflowGraph shape (experimental):

generateWorkflowGraph (today): picks first registered tool (or "echo"), emits a 3-node chain (tool → ai → ai). Override in tests with __test.dynamicGraph on createAgent.

Save as static workflow

After workflow:save:prompt, persist via session:

Vitest: packages/core/src/phase4.test.ts (repeating a similar task triggers save prompt).

Graph plugin (UI)

createGraphPlugin wires Plugin.onWorkflowGraph and onWorkflowNodeStatus for renderers (React Flow, Mermaid, logs):

Browser example: examples/workflow-demo-ui — server on :8788, Vite UI listens for workflow:generated, workflow:save:prompt, calls session.saveWorkflow.

See Streaming & wire protocol for POST /saveWorkflow and SSE event names.

Wire client

GET /capabilities includes dynamicWorkflows: true when enabled.

Promote dynamic → static

workflowGraphToDef maps graph nodes to WorkflowStepDef (tool / ai kinds) and saves to the same store static workflows use. Saved workflows keep the graph id unless you change the name field on the definition.

Limitations (current code)

  • Not a general NL planner — graph structure is template-based unless you pass __test.dynamicGraph.
  • Session-only entry — no agent.run() dynamic path; use agent.session().send.
  • Node types — dynamic graph supports tool and ai only (no branch / fn in generated graphs).
  • Experimental namespace — no semver guarantee on graph shape or generator.
  • planFirst on orchestration is unrelated and not wired.
