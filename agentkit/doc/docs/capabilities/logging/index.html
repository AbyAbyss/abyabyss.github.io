Logging and observability

Structured log events and token cost meter

AgentKit surfaces runtime activity as typed AG-UI events rather than only stdout. Set logging.level to control log emissions from the agent shell, and subscribe to cost:update for per-turn token and cost estimates from the active provider.

Use this for activity feeds in custom UIs, debug panels in development, and billing meters — not as a replacement for your host app's production log aggregator yet.

Config

The reasoning loop also emits log at info level for tool starts (see orchestrator/loop.ts). Sessions emit log on cancel.

Wire client

All events stream over SSE — see Streaming. No separate logging HTTP API.

EventPayload (summary)
log{ level, message }
cost:update{ model, inputTokens, outputTokens, cost, ... }
tool:call / tool:resultTool tracing
error / doneTurn outcome

OpenTelemetry spans

Set logging.otel: true to emit JSON span records from the reasoning loop (agent.run, agent.step, agent.tool). This is a lightweight file-friendly format, not a full OTel exporter SDK. Pair with cost:update and log events for custom dashboards.
