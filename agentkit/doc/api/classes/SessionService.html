    Class SessionService

    The append-only session log and the projection of model history from it.

    The invariant this service exists to enforce: model-visible means logged. Anything that reaches a model request must be reconstructable from the log, which is what makes fork, resume, replay, and durable UI possible at all rather than each being its own feature.
