01Why AgentKit

An agent engine, not a framework.

Most agent tools make you adopt their UI and their hosting. AgentKit is just a library you import. Configure an agent once, then run it headless on a server, in a CLI, or stream it to any frontend. You stay in control of the product; the SDK handles the hard parts of running a model loop in production.

1
Configure

Call createAgent({ … }) — pick a model, add your tools, memory, and MCP servers. One config object, fully typed.

2
Run or stream

Use agent.run() for a one-shot typed result, or agent.session() for a live, interactive conversation.

3
Render

Typed events stream out — tokens, plans, approvals, cost. Your UI just listens and draws. No lock-in.

🎛️

Bring your own UI

React, Vue, Svelte, a terminal, or no UI at all. The engine never touches your front end.

🔌

Any model provider

Anthropic and OpenAI built in, or register your own. Route to a different model per call.

🧩

Tools & MCP

Zod-typed tools plus Model Context Protocol servers over stdio or HTTP — connect real data and actions.

🛡️

Human-in-the-loop

Plan mode, approval gates, and elicitation arrive as events you can pause on and resolve.

🧠

Smart context

Adaptive TOON encoding and automatic compaction keep prompts small and cut token cost.

🧪

Test without keys

A deterministic mock provider and record/replay harness let you build and CI-test with zero API calls.

05Polyglot clients

Connect from any language.

The engine stays TypeScript — but the AG-UI wire is just HTTP + SSE, so any language can drive a session. Here is the same flow from the clients/python client.

TypeScript Python

Thin by design

Language clients don't re-implement the engine — they connect to @agentkit/server and receive the same typed events as @agentkit/client.

  • Same event names — stream:token, plan:created, approval:request, done.
  • Stdlib only — no heavy dependencies; manage it with uv (uv sync, uv run).
  • Full session control — send, approve, answer, cancel, close.
Python · clients/python
from agentkit import connect # Same AG-UI wire the JS client speaks — engine stays TypeScriptsession = connect("http://localhost:8787", token="...") # Subscribe to typed events streamed from @agentkit/serversession.on("stream:token", lambda e: print(e["token"], end=""))session.on("plan:created", lambda e: print("plan:", e["steps"], "steps"))session.on("approval:request", lambda e: session.approve(e["requestId"]))session.on("done", lambda e: print("\n✓ complete")) # Send a task — the agent plans, streams, and pauses for approvalsession.send("Draft and send the weekly report")session.close()
