    Class JobRuntime

    Background work, kind-agnostic.

    A background shell command, a detached subagent, and a long PTY send are the same shape once started: something producing output that a model wants to poll, read, and stop. Modelling that once means job_list / job_output / job_kill cover producers that did not exist when the tools were written.
