Models & switching

Registry, hot-swap, wire parity, and extension levels

Switch models mid-session without custom HTTP or provider glue. The model registry tracks entries; ModelRegistry.resolveActive() picks the current default on every session.send() and agent.run() — no server restart required.

Quick start (Pattern E)

Same contract everywhere

In-process agent.models, @agentkit/client session.models, and @agentkit/server routes expose the same verbs:
