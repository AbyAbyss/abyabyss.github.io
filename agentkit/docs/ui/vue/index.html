Vue

Any backend

@agentkit/vue runs in the browser and talks to an AgentKit server over the wire protocol. The server can be written in TypeScript, Python, Go or Rust: the composables below work unchanged against all four, so you can move the backend to another language without touching this code. See Serve over HTTP for the server side in each language.

useAgentSession(url, opts?) mirrors @agentkit/react: connects on mount (retrying with backoff, status "reconnecting", while the server is down) and exposes ready, session (a shallowRef), status, error, on, send(input, options?), approve, reject, answer, cancel, saveWorkflow, and a rolling events log.

State composables take the session (or the session ref) and return refs. They wrap the pure reducers from @agentkit/client, so they behave exactly like the React hooks.

ComposableReturns (refs unless noted)
useConversation(session, { includeNested? })messages, streaming
usePendingRequests(session)approvals, questions; approve, reject, answer
useWorkflowRun(session)runs, generating, savePrompt, list; run(id, input?), generate(task), refreshList
useWorkflows(session)workflows; refresh, get, remove, save
useMcp(session)servers, tools; refresh, connect, disconnect, reload, add, remove, completeAuth
useUsage(session, { maxHistory? })tokens, inputTokens, outputTokens, cost, history
useEventLog(session, opts?)a computed list of audit rows
useTodos(session)todos; edit(id, patch)
usePlan(session)a computed plan
useModels(url, { token?, tenant? })ready, models, activeId, userConfigurable; setDefault, test, refresh

Composables unsubscribe when the component (or effect scope) is disposed. Wire details: the wire protocol.

Many sessions

Section titled “Many sessions”

useSessionHub(url, opts?) creates a createSessionHub on mount (a shallowRef, null before) and closes it on unmount. useSessionState(hub, sessionId) returns a shallowRef of that session’s { conversation, pending, workflow, plan, todos, usage }; both arguments may be refs or getters. useHubSessions(hub) is a shallowRef of the ids it knows. hub.value.session(id) is a ClientSession the composables above accept. See Client.
