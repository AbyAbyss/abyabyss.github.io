Two levels, one runtime

Start with a config. Grow into a kernel.

Most projects never need more than createAgent. When a config object isn't enough, the same import gives you the plugin kernel the engine is built on. No fork, no second library.

Level 1 · A task

createAgent, a typed result

Validated with Zod at construction. Pass a schema and the output comes back typed and checked.

import { createAgent } from "@agentkit/core";
import { z } from "zod";

const agent = createAgent({ provider: "anthropic" });

const result = await agent.run("Summarise this changelog", {
  output: z.object({
    summary: z.string(),
    risk: z.enum(["low", "high"]),
  }),
});

result.output; // typed and validated
Level 2 · A harness

The plugin kernel underneath

Every battery ships as a plugin on this spine. Replace any part of a turn through public APIs.

const runtime = createRuntime();
runtime.plugin(agentRuntime());
runtime.plugin(modelPlugin("anthropic"));
runtime.plugin(myTools);
runtime.plugin(approvalPolicy, { deny: ["drop_table"] });
runtime.plugin(compaction, { contextLength: 200_000 });
await runtime.start();

const session = await runtime.agents.create({ sessionId: "a1" });
await session.send("refactor the auth module");

Observability
Traces shaped like agents.

      
Two products, one boundary. The SDK batches spans to one endpoint with an ingest key; the control plane stores them and draws the screens. Telemetry is off until you turn it on.
