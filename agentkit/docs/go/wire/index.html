The Go server

Package server is plain net/http. server.Serve runs a listener of its own and returns its URL:

To mount the routes in a mux of your own, server.CreateAgentHandler(a, opts) returns an http.Handler; with BasePath set it answers under that prefix, and anything else goes to Next (or 404):

The routes are the TypeScript list: POST /session, GET /events (SSE with keep-alive pings), GET /events/all, POST /send, /approve, /reject, /answer, /cancel, GET /approvals, /history, /artifacts, GET|POST /mode, /todo/edit, /workflows*, /mcp* (with the OAuth callback), /rag/*, /models*, /health, /capabilities. With Transport: server.TransportWebSocket, /events is a WebSocket. Auth, tenant isolation (TenantHeader), CORS, Host checks (AllowedHosts, default on a loopback bind), the 4 MiB body limit and the session cap (MaxSessions) are ported from handler.ts.

Each event stream has its own queue and goroutine, so a slow client never blocks the agent, and a session route waits for its streams to flush before it replies: /send cannot answer ahead of its tokens.

The Go client

Package client talks to any AgentKit server:

It reconnects dropped streams with backoff, client.ConnectWithRetry waits for a server that is still starting, and client.ConnectAgents(url, opts) talks to ServeAgents. The session hub folds events with the same reducers as the TypeScript client (conversation, pending, todos, usage, workflow), in package client/state.

Two things differ from TypeScript. Handlers for server events run on the stream's reader goroutine, so keep them short or hand work off. And Close() returns at once (a handler may call it) while Shutdown(ctx) also waits for that goroutine. The event stream starts with the first subscriber; wait for session.Status() == client.StatusOpen before a Send whose events you must not miss.

How the sameness is checked

The client contract, in all sixteen pairings. A contract host in each language (sdks/conformance/contract/ts_host.mjs, python_host.py, the Go one in sdks/go/internal/contracthost and the Rust examples/contract_host.rs) builds an agent from a JSON config and serves it on a free port (POST /serve, /serve-agents, /close). TypeScript's packages/server/src/client-contract.test.ts runs unmodified against any host, and so do its Python, Go and Rust ports:

The wire frames, byte for byte. sdks/conformance/fixtures/wire.json holds the AG-UI frames the TypeScript adapter produces for every event name; the Go server replays them exactly. CI regenerates every fixture from the TypeScript source and fails on any difference.
