    Class SubprocessService

    Base class for a service. A service is reachable at ctx.<name> by every plugin in the tree, and its this.ctx is rebound to whichever context is reading it — so a registration made inside a service method is owned by the calling plugin and unwinds when that plugin does.

    Because callers see a per-context view, keep mutable state in fields that hold objects (a Map, Set, or array), never in reassigned scalar fields: this.items.set(k, v) mutates the shared instance, this.count = 1 would write to one caller's view.
