Getting started with Rust

sdks/rust is a full port of the AgentKit engine, not a client wrapper: providers, tools, memory, MCP, RAG, workflows, approvals, the plugin kernel, the workspace, the server and the client all run in your process, on Tokio. TypeScript stays the reference; shared fixtures and a client contract suite check that the four engines behave the same.

The crate is published as headless-agentkit and imported as agentkit (the crate named agentkit on crates.io is an unrelated project). Releases are tagged sdks/rust/vX.Y.Z; the version tracks @agentkit/core's.

Install

Rust 1.88 or newer (edition 2024).

The default build runs the mock provider, the in-memory stores and SQLite (bundled, no system library). Everything else is a Cargo feature, so a program that never asks for a backend does not link its driver:

Providers are raw HTTP over one reqwest client with rustls, so no vendor SDK or system OpenSSL is needed.

Your first agent

Every call that does I/O is async, and every fallible call returns Result<_, AgentError> where TypeScript throws.

Set ANTHROPIC_API_KEY (or another provider's key). The config is a typed struct whose fields follow the TypeScript keys in snake_case; see Config in Rust.
