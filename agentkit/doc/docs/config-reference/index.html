agent.session(opts?) / agent.mcp

Agent methods: run, session, on, setMode, mcp, models, workflow, workflows, capabilities.

Session methods: on, send, setMode, saveWorkflow, answer, approve, reject, editTodo, cancel, history, close.

MCP: servers, tools, resources, connect, disconnect, reload, call, expose.

Models: agent.models.list/add/remove/setDefault/test/usage/refresh — add requires provider.userConfigurable: true; refresh syncs Ollama tags via listOllamaModels().

Workflows: agent.workflow(name), agent.workflows.run/list/get/delete.

Providers implementing embed(text) expose embeddings for retrieval and similarity checks (e.g. dynamic workflow repeat detection).

Large tool results are stored as compact handles; the model can call expand_tool_result to fetch the full payload.

Harness replay CLI

Binary ships from @agentkit/core. See Harness.

Wire (@agentkit/server / @agentkit/client)

  • serve(agent, { port, host?, transport?, auth?, tenantHeader? }) — transport: 'sse' (default) or 'websocket'; includes model routes and enriched /capabilities
  • handleModelRoutes(agent, req, res, pathname) — reuse in custom servers (returns true if handled)
  • connect(baseUrl, { token?, tenant?, sessionId? }) with send, approve, answer, on, models.*

UI bindings

@agentkit/react is the reference UI package. Vue and Svelte are thin scaffolds; themed CSS is upcoming.

@agentkit/react

  • useAgentSession(url, { token?, tenant? }) returns { ready, session, on, send, events }
  • useModels(baseUrl, { token?, tenant? }) returns { ready, models, activeId, userConfigurable, setDefault, test, refresh }
  • Components: Chat, Timeline, TodoPanel, ApprovalGate, ChoiceCards, ToolList, ModelPicker, CostMeter, DevLog, WorkflowSaveDialog

@agentkit/vue (scaffold)

  • useAgentSession(url, opts?) Vue composable with the same return shape as React
  • Components: Chat, TodoPanel, ApprovalGate, ModelPicker (minimal stubs)

@agentkit/svelte (scaffold)

  • useAgentSession(url, opts?) returns Svelte stores; call connect() from onMount
  • Chat.svelte source scaffold; prop contracts exported from the package entry

Python client (clients/python, package agentkit)

Stdlib-only scaffold over the same AG-UI HTTP routes as @agentkit/client. Manage with uv (uv sync, uv run pytest).

The engine stays TypeScript. The wire protocol is the standard; language clients stay thin.
